## Установка

Остановите WebUI. Запускайте из этой папки, расположенной вне целевого A1111:

```powershell
python install.py verify
python install.py check "<A1111_INSTALL_DIR>"
python install.py install "<A1111_INSTALL_DIR>"
```

На Colab используйте `/content/A1111` вместо Windows-пути. После установки
полностью перезапустите Python/WebUI; обновления браузера недостаточно для хуков.

`check` не меняет файлы. UNKNOWN означает другую версию исходников: сначала
проверьте различия. `--allow-unrecognized` разрешает замену неизвестных полных
файлов и не отключает проверку контекста точечных патчей.

`processing.py` изменяется шестью контекстными фрагментами — Hires-маркером,
очисткой после генерации, двумя методами close и двумя дополнениями conditioning cache.
Остальной REGION/TONEG-код сохраняется. Другие
перечисленные в manifest исходники заменяются целиком, поэтому универсальная
совместимость с любой A1111, Forge/reForge/SD.Next не заявляется.

Установщик использует стандартную библиотеку Python, не скачивает Torch,
не запускает WebUI и автоматически сохраняет изменяемые оригиналы в
`.lora-studio-backups/<ID>`. Команды отката:

```powershell
python install.py backups "<A1111_INSTALL_DIR>"
python install.py rollback "<A1111_INSTALL_DIR>" ID
```

Runtime-наборы используют уже установленный Torch и CPU. Ранее
для него создано отдельное окружение `<HISTORICAL_AUDIT_ROOT>/venv` с
`torch 2.10.0+cpu`; кэш pip и временные файлы установки также находятся на D:.
Это тестовое окружение, не полноценный venv A1111.

test_lora_studio_access.py использует уже установленные FastAPI/HTTPX, не Torch.
Никаких зависимостей установщик не ставит. На сервере с --api-auth разрешаются
верные API credentials; на Gradio с auth также принимается действующая сессия.
Без настроенной авторизации локальный режим остаётся открытым. Browser write
с чужим Origin отклоняется. За reverse proxy нужна отдельная проверка Origin и
корректного внешнего scheme/host; не отключайте auth ради устранения ошибки proxy.

Реальная генерация, пользовательские checkpoint/LoRA и обучение TI здесь не
запускались. Для окончательной проверки нужен тот же SDXL в рабочей GPU-среде.
Часть FP8/TI и LoRA/manual_cast проверена на CPU; до переноса идей из
`<HISTORICAL_EXTENSIONS_DIR>` остаются реальные внешние расширения, матрица версий,
GPU/checkpoint и настоящий Gradio (браузерный mock-стенд уже проверен).
Обучение SDXL TI не добавлено: trainer выдаёт явное
сообщение вместо позднего падения. Защита pickle не отключается; пакет обновляет
modules/safe.py, поэтому неизвестную версию этого файла сначала сравните.
Не копируйте
один lora_patches.py отдельно: он требует modules/patches.py из того же кандидата.
