# Создание справки LoRA Studio во время работы приложения

**Интерактивная справка** отделена от исторической технической документации в `docs/EN/` и `docs/RUS/`. Старые отчёты аудита по умолчанию не устанавливаются в A1111. Этот файл предназначен для разработчиков; статьи интерфейса расположены в `files/extensions-builtin/Lora/help_documentation/`.

## Структура

```text
files/extensions-builtin/Lora/
  lora_help_registry.py
  help_documentation/
    en/getting-started.md
    ru/getting-started.md
    fr/getting-started.md
    registry/getting-started.json
```

Реестр просматривает языковые папки **при каждом запросе API**. Новые Markdown-файлы в установленной папке справки появляются после повторного открытия или обновления справки. Для установки нового Python или JavaScript кода нужно перезапустить A1111.

## Создание статьи

1. Выберите уникальный идентификатор из латинских строчных букв, цифр и дефисов, например `negative-weights`.
2. Создайте `help_documentation/en/negative-weights.md`. Начните файл с заголовка `# Title`, затем добавьте краткое описание и основной текст.
3. Добавьте перевод с **тем же идентификатором** в `ru/negative-weights.md` или другую языковую папку. Если перевода нет, отображается английская версия.
4. При необходимости создайте JSON в `help_documentation/registry/negative-weights.json`.
5. Выполните `python run.py help-audit`.

### Необязательный JSON

```json
{
  "order": 10,
  "contexts": ["studio.negative_weights"],
  "related": ["weights-and-rank", "curves-and-timing"],
  "tags": ["weights", "negative"]
}
```

JSON не нужен, если статье не требуются связи или привязка к кнопке. Заголовки и аннотации берутся из локализованных Markdown-файлов. Поле `related` содержит идентификаторы статей, а `contexts` — независимые от языка идентификаторы элементов UI. Это позволяет менять назначение кнопки `?`, редактируя JSON вместо кода JavaScript.

## API

- `GET /sdapi/v1/lora-studio/help?locale=ru` возвращает список статей, аннотации и связи.
- `GET /sdapi/v1/lora-studio/help/getting-started?locale=ru` возвращает текст статьи.
- Оба маршрута используют существующую защиту API LoRA Studio, не изменяют промпты и параметры генерации.

## Безопасность

Просмотрщик поддерживает ограниченный Markdown: заголовки, абзацы, списки, выделение, блоки кода и безопасные ссылки. HTML показывается обычным текстом и не выполняется. Размер статьи ограничен 64 КиБ, JSON — 16 КиБ. Не размещайте в справке секреты и личные данные.

Интерфейс поддерживает 10 языков. Сейчас **девять статей полностью представлены на английском и русском**; остальные языки используют английскую версию, пока не создан перевод.

## Проверка

```powershell
run.bat verify
run.bat help-audit
run.bat docs-audit
run.bat test
```

В A1111 нажмите `?`, проверьте поиск, связанные темы и смену языка без изменения текста промпта. Работа в браузере, Gradio и с GPU требует отдельной проверки.
