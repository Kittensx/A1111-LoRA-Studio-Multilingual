# Переносимые инструкции по историческим сборкам (русский)

Текущий пакет LoRA Studio устанавливается с помощью `run.py` и `install.py`.
**Не запускайте `tools/build_v10.py`–`build_v15.py` для установки расширения.**
Это исторические скрипты восстановления старых сборок, которым нужны исходные
деревья и снимки файлов, отсутствующие в публичном репозитории.

## Проверка текущей версии

```powershell
python run.py verify
python run.py docs-audit
python run.py help-audit
python run.py test
python run.py check "<A1111_INSTALL_DIR>"
```

Подставьте собственный путь к A1111 вместо `<A1111_INSTALL_DIR>`.
Шесть технических документов не являются обязательными для установки.
При необходимости добавьте `--docs-language EN` или `--docs-language RUS`.

## Исторические сборки (для разработчиков)

Для воспроизведения прошлой версии нужен исходный код A1111 соответствующего
периода, а иногда и резервная копия вместе с пакетом предыдущей версии.
**Эти входные файлы не включены в репозиторий.** Теперь требуется отдельная
директория `--output` с копией предыдущего пакета; скрипты запрещают запись
в текущий репозиторий.

```powershell
python tools/build_v15.py --help
python tools/build_v15.py --source "<A1111_SOURCE>" --backup "<BEFORE_SNAPSHOT>" --base "<V14_PACKAGE>" --output "<SEPARATE_V14_COPY>"
```

Вместо `--backup` можно использовать `--before`. Поддерживаются переменные
окружения `LORA_STUDIO_SOURCE`, `LORA_STUDIO_BACKUP`, `LORA_STUDIO_BASE`,
`LORA_STUDIO_OUTPUT`. Скриптам v13 и v14 достаточно `--source` и `--output`.
Для v10–v12 и v15 также нужны снимки исходного состояния. Скрипт v12
ожидает исторический `modules.zip` рядом с исходными файлами A1111.
Старые сборщики v3–v9 используют собственный параметр `--base`.

**Полный запуск исторических сборок не проверен:** требуются исходные входные
файлы соответствующего периода. Эти скрипты не предназначены для выпуска
текущей многоязычной версии.

## Исторические документы и доказательства

Пути `<HISTORICAL_AUDIT_ROOT>`, `<A1111_SOURCE>` и
`<HISTORICAL_EXTENSIONS_DIR>` в отчётах — обезличенные исходные пути,
а не обязательные каталоги. Результаты и даты отчётов не пересчитывались.
`<HISTORICAL_AUDIT_SCRIPTS>` указывает на сторонние скрипты, не входящие
в репозиторий.

Журналы в `evidence/` и исходные ZIP в `archive/` оставлены без изменений.
В них могут встречаться пути с исходного компьютера. Не используйте старые
журналы как руководство по установке. Целостность текущего пакета
проверяется через `manifest.json` командой `python run.py verify`.
