# Самостоятельный аудит v12 → v13 — 2026-11-12

## Что проверялось заново

Это не пересказ предыдущего отчёта. Были повторно сверены точечные diffs с
резервной копией до внешнего аудита, install manifest/payload/рабочий проект,
архив v12, вызовы загрузчиков и конкурентные ветви `Options.set`.

Проверено, что ZIP v12 и его папка совпадают entry-by-entry; SHA256 v8–v11 не
менялись. `install.py check` рабочего проекта перед новой поправкой дал 0 changes
и 0 unrecognized. Следовательно, прошлый пакет не был испорчен после запечатывания.

## Найденный и исправленный дефект

`Options.set(key, value, run_callbacks=False)` обновляет значение без запуска
callback намеренно: этим пользуются операции, которые не должны перезагружать
модель/VAE. После v12 возникал редкий параллельный сценарий:

1. Первый поток запускает долгий callback для значения A.
2. Второй поток задаёт B с `run_callbacks=False`.
3. После callback A владелец замечает новую версию B и ошибочно вызывает callback
   ещё раз уже для B.

Это нарушало флаг второго вызова. В v13 хранится намерение callback для каждой
версии. Владелец текущего callback завершается без неявного запуска, если последнее
изменение было data-only. Добавлен многопоточный тест с блокировкой/освобождением,
который до поправки падал бы ожиданием `['first']`, а получил бы
`['first', 'data-only']`.

Ограничение осталось сознательным: data-only изменение во время выполняющегося
callback не откатывает уже совершившийся эффект A. Оно гарантирует только то, что
новый callback для B не будет запущен тайно. Нельзя безопасно отменить произвольный
побочный эффект A без транзакционного API каждого callback.

## Не найдено новых подтверждённых runtime-дeфектов

- VAE: exact sidecars, duplicate labels и сигнатуры кэша согласованы с тестами.
- Checkpoint: forced read доходит до загрузки с диска; обычный cache hit требует
  совпадения подписи файла.
- TI: safetensors проверяется до чтения tensor payload; dual rows/widths не
  «исправляются» небезопасной конвертацией.
- LoRA: SD3/Flux metadata не становится ложным SD1; поддержка Flux не заявлена.
- Установка: runtime assets обязаны иметь operation, а REGION отдельно покрыт
  отрицательным тестом.

Это статический/CPU аудит. Он не доказывает реальные GPU качество, VRAM, Gradio,
пользовательские модели или все внешние расширения. Эти пределы не меняются.
