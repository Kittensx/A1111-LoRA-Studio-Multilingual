# Проверка выпуска и диагностика контрольных сумм

Этот репозиторий устанавливает полные замены файлов A1111. Исходный код LoRA Studio и его лицензия сохранены. Проверки ниже выполняются **без запуска A1111** и не заменяют испытания приложения и GPU.

## Перед публикацией выпуска

В корне репозитория выполните:

```powershell
python run.py verify
python run.py docs-audit
python run.py help-audit
python run.py test
```

Проверка пакета вычисляет SHA-256 для **точных байтов** всех ресурсов из манифеста. Проверка документации отдельно сверяет пары английских и русских документов и шесть необязательных документов. Проверка справки проверяет связи между темами и резервные языки.

После сохранения изменений в Git выполните:

```powershell
python run.py release-verify
```

Команда создаёт временный ZIP из **зафиксированного HEAD**, распаковывает его и проверяет ресурсы, документацию и справку. Нужны Git и чистый рабочий каталог. Репозиторий не изменяется, публикация не выполняется.

## Как понимать ошибки контрольных сумм

Установщик теперь показывает *все* несовпадения за один запуск:

- `missing` — требуемый файл отсутствует
- `line endings changed` — преобразование CRLF/LF даёт точно ожидаемый SHA-256
- `content/bytes differ` — разница не объясняется только переводами строк

Ни один файл не исправляется автоматически. Восстанавливайте **байты нужного выпуска**, а не случайную копию исходного v15. Файлы, специально изменённые для многоязычной версии, должны оставаться изменёнными. Не пересчитывайте все контрольные суммы только ради прохождения проверки: так можно скрыть ошибки.

Файл `.gitattributes` защищает байты ресурсов при работе с Git в Windows и Linux. После каждого выпуска проверяйте архив Git и не допускайте неявного изменения переводов строк редактором.

## GitHub Actions

`.github/workflows/verify.yml` проверяет пакет в Windows и Linux с Python 3.10/3.12 и Node.js 22. Запуск выполняется при отправке изменений в `main`, в запросах на включение изменений и вручную. При необходимости можно сделать проверки обязательными в настройках защиты ветки.

Автоматическая проверка **не** устанавливает и не запускает A1111, не проверяет работу моделей и не публикует выпуск.
