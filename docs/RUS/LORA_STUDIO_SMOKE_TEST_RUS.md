# LoRA Studio — контрольный список ручной проверки Phase 4

Запускайте только на уже настроенном WebUI. Для этого списка не нужно скачивать модели или генерировать изображения. Запишите ревизию WebUI, браузер и наблюдаемые ошибки перед исправлением кода.

Для изолированной DOM-демонстрации откройте `test/lora_studio_fixture.html` и выберите **Run UI checks**. Заглушка API сохраняет данные только в памяти; она не проверяет Gradio и качество изображения.

```bash
node --test test/lora_quick_presets.test.cjs test/lora_combinations.test.cjs test/lora_studio_dom.test.cjs
```

Этот набор проверяет рецепты и поведение событий/состояний через минимальную DOM-заглушку, но не заменяет визуальную и accessibility-проверку настоящего браузера. Фикстура намеренно включает конфликтный сброс CSS-форм, чтобы проверить контраст полей в светлой и тёмной темах при наличии или отсутствии переменных Gradio; Node-тесты CSS-проверку пропускают.

| Проверка | Действие | Ожидаемый результат |
| --- | --- | --- |
| Разбор сохранённого промпта | Откройте txt2img и img2img с тегами `lora`, `lyco`, `loractl`, включая повторяющиеся имена. | Каждое вхождение показывается отдельно; обычный текст и неподдерживаемые теги не изменяются. |
| Безопасность черновика | Измените LoRA и отмените; повторите и нажмите Apply. | Отмена ничего не меняет; Apply обновляет лишь выделенное вхождение и отвергает устаревший промпт. |
| Расширенные значения | Заполните Hires, тайминг, кривую, сырой вес блока и `lbwe`; примените и откройте снова. | Все значения, включая пустое/inherit, возвращаются без потерь. |
| Совместный TE/U-Net/DYN | Проверьте `<lora:name:te=0.3:unet=0.8:dyn=16>` и `:0.3:0.8:16`, затем кривую U-Net с Hires и масками. | Все поля независимы; выключение DYN убирает только ранг; верхний регистр имён сообщает о регистрозависимости. |
| Незавершённый ввод | Очистите обязательный вес/точку; введите DYN `2.5`, `0`, `-1` или переполнение. | Нет тихой подмены нуля или обрезки ранга; ошибка видима; промпт не изменён. |
| Согласованность полей | Меняйте быстрый TE, затем точный TE и кривую. | Поля синхронизированы; кривая не подменяется скаляром, ввод в фокусе не теряется. |
| Сохранение фокуса | Редактируйте точку кривой, ячейку блока, `lbw` и `lbwe`; переключайте фокус. | Активное поле не уничтожается повторным рендерингом, значения и график обновляются. |
| Пустые групповые операции | Оставьте пустым блок и команды Set all/Set group. | Пустота не равна нулю, ошибка блокирует Apply, пустая команда ничего не меняет. |
| Резервная копия JSON | Откройте импорт/экспорт, вставьте текст, очистите поле и вызовите перерисовку. | Текст, включая намеренную пустую строку, сохраняется; поле можно растянуть. |
| Контекстное меню промпта | Щёлкните правой кнопкой внутри LoRA-тега, измените поля, затем Cancel/Escape, повторите с Apply. | Quick tune не изменяет промпт до Apply; обычный текст сохраняет штатное меню браузера. |
| Диагностика блоков | Проверьте подходящий `.safetensors`, Flux, flat DiT и неопределённый случай. | Только чтение, без смены профиля/промпта; различаются раскладки D/S и B; сомнения явно помечены. |
| Sidecars | Добавьте `.txt`, `.description.txt` или `.json` и явно запустите просмотр. | Приоритет описаний JSON → `.txt` → `.description.txt`; вставка trigger только по щелчку. |
| Пресеты | Сохраните v3 с Hires/elemental, добавьте в избранное, примените, экспортируйте/импортируйте v1/v2. | Значения восстанавливаются; недавние записи локальны браузеру; v1 сохраняет действующий Hires. |
| Общий список пресетов | В Quick tune/Studio откройте простой режим, маску блоков, модулей и сохранённый пресет. | Выбор лишь показывает описание; Use preset меняет черновик, Apply — только выбранный тег. |
| Владение черновиком | Откройте Quick tune при развернутой Studio, отредактируйте и передайте в Full Studio. | Одна транзакция редактирования без тихого сброса; фон неактивен. |
| Темы и размеры | Проверьте светлую/тёмную тему, узкое окно, раскрытые формы и карточку. | Контролы читаемы, всплывающее окно помещается и прокручивается. |
| Доступность | Tab/Shift+Tab/Enter/Space по кнопкам, полям, спискам и блокам. | Видимый фокус, осмысленные имена, отсутствие ловушки фокуса. |
| Перезагрузка | Обновите браузер, Extra Networks и переключите вкладки. | Нет дубликатов Studio; пресеты загружаются; черновик никогда сам не записывается в промпт. |

При ошибке сохраните исходный промпт, точный тег LoRA, сообщение консоли и шаги воспроизведения. Одного полученного изображения недостаточно для подтверждения корректности: важны состояние UI и текст промпта.

Примечание исходного документа от 2026-10-29: 51 проверка событий и состояний прошла в симулированном DOM (17 Node-тестов), добавлены варианты тем и защита от конфликтного сброса CSS. Реальный WebUI, Torch, модель и генератор не запускались; белая панель и визуальное отображение требуют проверки в настоящем браузере.
