# Исправления v10: результат и границы

2026-11-06. Проект: `<A1111_SOURCE>`.

В рабочие файлы внесены исправления всех 11 групп подтверждённых дефектов
последних аудитов: V9-1–5, C1–4 и L1–2. Собран отдельный пакет
`<HISTORICAL_AUDIT_SCRIPTS>/A1111-LoRA-Studio-Pack-v10`.
Это проверенный локальными тестами кандидат, не полная GPU/Gradio приёмка.

## Что сделано

| Находки | Исправление |
|---|---|
| V9-1 | SD3 native Embedding определяется по собственному embedding_dim; wrapper — по внутреннему слою |
| V9-2–4 | Валидация пресетов на snapshot, атомарный temp/fsync/replace config, публикация памяти только после успеха, общий process-local lock Options |
| V9-5 | Ошибочный Origin получает 403, не 500 |
| C1 | TI registry сверяет модель/encoder signature, повторно загружается при несовместимом binding |
| C2 | Conditioning key учитывает TI revision и LoRA payload/settings; одинаковый текст после refresh не возвращает старый tensor |
| C3 | Временные detachments возвращаются в finally; partial hooks/методы откатываются; lowvram/parallel flags публикуются после успешной установки |
| C4 | Защита от 0/0 и неустойчивого mean ratio в Original emphasis с сохранением weighted values и выходного dtype |
| L1 | Known EmbeddingsWithFixes разрешается в реальный слой; canonical/child aliases согласованы, weightless target сообщает имя и тип |
| L2 | Дополнительный SDXL upsampler candidate; SD1 не потерян, неоднозначность не угадывается |

L1 проверен не только конструктором: настоящее применение к обёрнутому Embedding,
повтор, смена силы, вставка TI и отключение возвращают ожидаемые значения.
L2 проверен полным load_network и merge/restore на маленьком настоящем Conv2d.
Файлов двух пользовательских LoRA здесь нет, поэтому полное исправление именно
этих safetensors и качество изображения остаются предметом удалённого smoke-test.

- Reported loading воспроизводитель: 4 PASS; SD3 baseline/consumer: 5 PASS.
- Ruff изменённых runtime/tests, кроме processing.py, PASS. В processing.py
  остаются два прежних F811 (sd_model/mask_blur); оба подтверждены на backup.
  Package verify PASS, check source
  changes=0 / UNKNOWN=0. 101 assets / 64 операции.

Проверка пакета обнаружила старую тестовую копию processing.py; сборщик исправлен,
повторный полный runtime suite из пакета PASS. Ошибки harness при введении новых
зависимостей исправлялись дополнением реального DB/transaction API, не удалением
assertions. Внешние исходные воспроизводители до адаптации сохранены в backup.

Финальная сверка обнаружила риск lock inversion в первоначальной реализации
Options.set: callback смены модели/VAE ожидает очередь генерации, а генерация
может менять настройки. Исправлено: config lock защищает изменение значения,
но не удерживается во время callback. Добавлен cross-thread тест; он проходит.
При ошибке callback откат также не затирает уже отличающееся новое значение.

## Установка на Colab

Остановить WebUI, распаковать v10 вне `/content/A1111`, перейти в папку пакета:

```bash
python install.py verify
python install.py check /content/A1111
python install.py install /content/A1111
```

При UNKNOWN или несовпадении контекста остановиться и сравнить файл. Не предлагать
безусловный --allow-unrecognized: полные замены могут затронуть чужие правки.
processing.py изменяется точечно шестью hunks, без замены большого parser/REGION
кода. Установщик делает backup и печатает rollback-команду. Затем нужен полный
restart Python/WebUI. Локальные исправления сами не попадут на Colab.

## Что не объявляется закрытым

- Реальная генерация на WAI-Illustrious-17 с пользовательскими LoRA и TI,
  refiner/Hires, GPU/FP8/low-VRAM и Gradio/proxy-auth — нужны интеграционные прогоны.
- UI U1/history/более удобные block sliders — отдельный UX-план, не эта серия исправлений.
- Конкурентные whole-library PUT остаются last-writer-wins; ETag/конфликт-UI нет.
  Прямые изменения opts.data и внешние процессы не покрываются process-local lock.
- Ошибки сторонних model_loaded callbacks намеренно перехватывает сам A1111;
  полной транзакции произвольных расширений эти изменения не обещают.
- Предыдущие остальные lint-замечания modules не являются частью этих 11 исправлений.

v8 и v9 не перепаковывались и не удалялись. Их SHA256 повторно совпали с
предыдущими квитанциями. Финальная SHA256 v10 публикуется после создания ZIP.
