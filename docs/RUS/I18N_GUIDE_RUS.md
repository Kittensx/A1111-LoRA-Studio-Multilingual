# Многоязычный интерфейс LoRA Studio — руководство по реализации и проверке

Этот пакет представляет собой **экспериментальную модификацию A1111 LoRA Studio Pack v15**. Он не является интеграцией с ImageGen и не должен устанавливаться в ImageGen. Сохраняйте исходники A1111 и уведомления о лицензии отдельно от будущего кода ImageGen. Изоляция в виде расширения сама по себе не гарантирует совместимости лицензий: условия использования кода необходимо проверить до распространения будущего расширения.

## Поддерживаемые языки и границы локализации

Интерфейс LoRA Studio поддерживает 10 языков: английский (`en`), русский (`ru`), французский (`fr`), испанский (`es`), итальянский (`it`), японский (`ja`), упрощённый китайский (`zh-CN`), бразильский португальский (`pt-BR`), немецкий (`de`) и корейский (`ko`). Выбор сохраняется в хранилище браузера под ключом `loraStudio.language.v1`. При первом запуске используется подходящий язык браузера.

В независимых словарях содержится **195 сообщений на каждый язык**: большая часть элементов LoRA Studio, подсказок, состояний и названий/описаний встроенных быстрых пресетов. Для отсутствующих переводов применяется английский текст. Некоторые динамические описания, ошибки серверной проверки и общий интерфейс A1111/Gradio не входят в эту локализацию. **Количество записей в словаре не означает, что переведена каждая возможная строка интерфейса.** Формулировки желательно дополнительно проверить носителями языков.

### Отделение перевода от данных LoRA

- `files/javascript/loraStudioI18n.js` — общий модуль: `register`, `t`, `setLocale`, `getLocale`, `canonical`, `supported`, `missingKeys`. Если словарь загрузится раньше модуля, регистрация будет отложена без потери данных.
- `files/javascript/loraStudioLocale*.js` — отдельные UTF-8-словари с устойчивыми идентификаторами `studio.*`. Переводы не встроены в алгоритмы генерации.
- `files/javascript/loraStudioView.js` и `files/javascript/extraNetworks.js` — переводят текст во время отображения. Переключение языка обновляет интерфейс, не изменяя исходный промпт и модель черновика. Известные сообщения о состоянии также обновляются.
- Названия моделей LoRA, теги промптов, исходные маски, пользовательские названия пресетов, введённый текст, JSON и параметры генерации **не переводятся**. Текст встроенных пресетов переводится только при отображении соответствующего встроенного режима.

## Добавление и изменение строк

1. Добавьте устойчивый ключ `studio.*` в английский словарь и тот же ключ — в остальные словари (до перевода будет использован английский запасной вариант).
2. Используйте `t("studio.namespace.stable_key", {name: modelName})` для текста интерфейса, сохраняя плейсхолдеры вида `{name}`. Для пользовательских значений используйте `textContent`, а не вставку HTML.
3. Не переводите программные коды, имена моделей и данные пользователя; переводить нужно только отображаемые подписи.
4. Выполните Node-тесты локализации, модели, пресетов и DOM. DOM-тесты проверяют, что при переключении языка байты промпта не меняются.
5. Обновите хеши изменённых файлов в существующем `manifest.json` — установщик отклоняет пакет с устаревшими хешами.

## Проверки без установки

```sh
python install.py verify
python -m unittest discover -s tests -v
node --test files/test/*.test.cjs
```

Для ручной проверки откройте `files/test/lora_studio_fixture.html` в настоящем браузере Chromium с доступом к локальным файлам либо используйте дополнительную страницу `files/test/lora_studio_browser_automated.html`. Проверьте тёмную и светлую темы, японский/китайский текст, ввод через IME, узкую ширину окна, управление с клавиатуры, вкладки txt2img/img2img, черновики и пресеты. Тестовая страница не запускает генерацию на GPU.

**Ограничения проверки:** симуляции Node и автономные тесты установщика не подтверждают корректность отображения в браузере и работы в настоящем A1111. Запуск Chromium в контейнере автора оказался ненадёжным; живая установка A1111/Gradio и генерация на GPU не проверялись. Установка изменяет файлы A1111, поэтому перед рабочим использованием обязательно проверяйте пакет на совместимой тестовой установке с резервным копированием и возможностью отката.
