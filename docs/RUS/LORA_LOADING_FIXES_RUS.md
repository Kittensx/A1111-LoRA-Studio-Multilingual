# Исправления загрузчика LoRA и совместимости embeddings — 2026-10-30

## Что изменилось

- `lora_keys.py` распознаёт суффиксы тензоров справа налево; пути CompVis с точками больше не схлопываются в родительскую группу UNet. Сохраняются нативные пути с подчёркиваниями, отображения diffusers, `alpha`/`scale`, суффиксы LoHa/LoKr/OFT/GLoRA и имена bundled textual inversion.
- Дублирующиеся нормализованные ячейки тензоров теперь вызывают явную ошибку вместо тихой перезаписи.
- `NetworkModuleLoraEmbedding` поддерживает обычные факторы up/down и A/B для `torch.nn.Embedding`. Проверяются ранг и обе размерности; прямое и транспонированное умножение выбираются только при однозначном соответствии. Для `lora_embedding_A/B` используется соглашение PEFT о транспонировании.
- Обработчики `Embedding.forward` и `_load_from_state_dict` подключены вместе с остальными хуками. В merge-режиме действует существующий механизм резервных копий и кеша. В functional-режиме адаптер применяется к временной матрице, затем выполняется индексный поиск. Целочисленные индексы токенов и позиций не приводятся к типу данных U-Net.
- Контракт активации используется для TE/Hires, весов блоков/модулей, alpha/scale, динамического ранга, повторных активаций и добавочного bias.
- Режим functional сохраняет базовую матрицу даже при `max_norm`; нормализация применяется к временной объединённой матрице. При отсутствии адаптера обычный путь Embedding остаётся без изменений.
- При переходе merge → functional без активных LoRA восстанавливаются прежние объединённые веса перед ранним выходом. Загрузка checkpoint сбрасывает старые резервные состояния адаптеров и кеш.
- Нормализация A/B больше не удаляет metadata `alpha`, `scale`, DoRA и bias. Исходный словарь не мутируется.
- Все параметры `bundle_emb.*.string_to_param.*` собираются вместе; внешние механизмы Textual Inversion и токенизации этим исправлением не переписываются.
- Отсутствие подходящих слоёв и дубли нормализованных весов завершаются явной ошибкой. Неподдерживаемые группы дают ограниченную диагностику; неудачные загрузки попадают и в общий перечень, и в подробный вывод.

## Преднамеренные ограничения

Это не универсальная поддержка всех экспортируемых Embedding-адаптеров. Форматы Embedding CP/LoCon-mid и DoRA отвергаются до определения проверенного контракта. Неоднозначная квадратная матрица up/down отвергается; явные ключи PEFT устраняют неоднозначность. Неверные формы не меняются автоматически, неподдерживаемые слои не пропускаются молча.

Журнал CEB содержит 790 путей слоёв и 1580 ключей up/down; пути приведены в `tests/ceb_reported_layers.json`. Поскольку журнал не содержит исходного префикса и размеров тензоров, регрессионный тест восстанавливает оба варианта `lora_unet.` и `diffusion_model.`. Это **не** проверка загрузки настоящего safetensors. Не были доступны и тензоры/заголовок Velvette: реальный экспорт должен быть проверен в пользовательском WebUI.

## Проверки (без загрузки Torch)

```bash
python -B -m unittest discover -s extensions-builtin/Lora/tests -v
```

Тесты используют заглушки NumPy и отдельные фактические AST-функции/классы с запретом импорта настоящего Torch. Проверяются разбор, математика факторов, преобразования типов, регистрация и отмена хуков, повторные вызовы, переключение режима, ранги, маски, Hires, `max_norm`, повторная загрузка и отключение адаптеров. Это не проверка реальной PyTorch/CUDA, жизненного цикла полной модели или генерации изображения; дополнительные зависимости не устанавливаются.
