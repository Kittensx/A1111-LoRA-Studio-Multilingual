# Quick presets and saved presets

Reusable settings without losing your own custom data.

Quick presets supply common starting points for weights and advanced controls. They create a draft; they are not applied to the prompt until you confirm.

## Saved preset library
- Save named Studio presets for repeated setups.
- Export the saved library as versioned JSON for backup.
- Import replaces library data only after confirmation.
- Built-in preset labels are localized. Names of user-created presets are kept exactly as entered.

Treat imported JSON as data. Review it before replacing a saved library.
