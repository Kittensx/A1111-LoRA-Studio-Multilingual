# Adding and editing LoRA tags

How the LoRA search, draft and tag preview work.

Studio edits LoRA tags in your current prompt, not model files on disk. Search by name or type a model identifier in the **Add LoRA** field.

## Draft workflow
- **Add as draft** prepares a new LoRA tag without committing it.
- Select an existing LoRA in **Active LoRAs** to edit its tag.
- Change controls, inspect the **Tag preview**, and choose **Apply to prompt**.
- **Discard draft** abandons unapplied changes. **Remove** stages removal of that tag only.

The displayed model name is data and is never translated when you change interface languages.
