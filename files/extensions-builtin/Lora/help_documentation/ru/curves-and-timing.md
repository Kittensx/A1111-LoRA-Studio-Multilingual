# Кривые и время активации

Расписание весов и параметры Hires.fix.

LoRA Studio поддерживает интервал активности LoRA и, на совместимых путях, кусочно-линейные кривые весов.

**Начало** и **Окончание** ограничивают активность LoRA во время семплирования. Пустые поля означают отсутствие дополнительного переопределения.

Редактор кривых позволяет задавать веса TE или U-Net по шагам. Проверьте форму кривой и тег перед применением.

Поля **Hires.fix** могут задавать отдельные веса для прохода высокого разрешения. Пустые значения наследуют обычные веса.

Сначала проверяйте сложные расписания на короткой генерации.
