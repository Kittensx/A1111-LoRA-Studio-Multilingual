# Языки и справочная документация

Смена языка, поиск и связанные темы.

Выбор языка в LoRA Studio переводит интерфейс и справку. Промпты, названия моделей и пользовательские пресеты автоматически не переводятся.

## Реестр справки
- Нажмите **?** рядом с элементом управления для открытия статьи.
- Ищите статьи и переходите по разделу **Связанные темы**.
- Реестр во время работы ищет `help_documentation/<locale>/<topic>.md`.
- Необязательные файлы `help_documentation/registry/<topic>.json` определяют связанные статьи и контексты.
- Если статьи нет на выбранном языке, отображается английская версия с предупреждением.

Новые статьи обнаруживаются при повторном открытии или обновлении списка. После обновления Python API перезапустите A1111.
