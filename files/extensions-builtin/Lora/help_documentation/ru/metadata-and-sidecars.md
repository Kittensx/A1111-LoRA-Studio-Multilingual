# Метаданные и сопутствующие файлы LoRA

Источники описаний и подсказок триггеров.

LoRA Studio может читать заголовок метаданных safetensors и сопутствующие файлы рядом с моделью.

- **Метаданные** извлекаются из ограниченного JSON-заголовка `.safetensors`; тензоры не загружаются.
- **Сопутствующие файлы** могут иметь расширения `.txt`, `.description.txt` и `.json`.
- Предлагаемые триггерные слова — только подсказки, их следует проверять.

Просмотр файлов не меняет промпт. Считайте сторонние описания недоверенными данными.
