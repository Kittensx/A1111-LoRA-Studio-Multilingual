# Быстрые и сохранённые пресеты

Повторное использование параметров и резервные копии.

Быстрые пресеты задают начальные параметры, но не применяются к промпту до подтверждения.

## Библиотека
- Сохраняйте именованные пресеты для повторной работы.
- Экспортируйте библиотеку в версионированный JSON.
- Импорт заменяет библиотеку только после подтверждения.
- Названия встроенных пресетов переводятся, а пользовательские названия сохраняются без изменений.

Проверяйте импортируемый JSON перед заменой библиотеки.
