# Добавление и редактирование тегов LoRA

Поиск моделей, черновики и предварительный просмотр.

Студия изменяет теги LoRA в текущем промпте, а не файлы моделей. Введите название модели в поле добавления.

## Работа с черновиком
- **Добавить как черновик** создаёт изменения без записи в промпт.
- Выберите существующую LoRA в списке активных моделей.
- Настройте параметры, проверьте предварительный просмотр, затем примените изменения.
- **Отменить черновик** удаляет незавершённые изменения. **Удалить** сначала подготавливает удаление тега.

Имена моделей не переводятся при смене языка интерфейса.
