# Веса TE и U-Net, динамический ранг

Основные ползунки и параметр DYN.

**TE** регулирует вес в текстовом энкодере для поддерживаемых LoRA; **U-Net** — вес основного денойзера. Поддержка зависит от архитектуры.

- Начинайте с умеренных значений и оценивайте результат.
- Быстрые параметры удобны для простых изменений.
- Точные веса позволяют вводить значения вручную.
- **DYN** задаёт ограничение ранга для поддерживаемых матриц. Отключение использует полный ранг; некоторые адаптеры игнорируют DYN.

Для сравнения результатов сохраняйте копию промпта.
